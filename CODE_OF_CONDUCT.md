# Code of Conduct

Be direct, respectful, and useful.

This project welcomes technical disagreement. Keep critique focused on the work, explain tradeoffs clearly, and assume other contributors are trying to improve the project.

Unacceptable behavior includes harassment, personal attacks, discriminatory language, publishing private information, or repeatedly derailing technical discussion.

Maintainers may edit, hide, or remove comments and may block participants who make the project unsafe or unproductive.
