JuneAI — System Architecture

How the local LLM assistant reads, thinks, and writes — from user message to structured memory.

Diagram 01
System Layers
The three layers of JuneAI: the Streamlit UI the user sees, the LangGraph agent loop that does the thinking, and the local memory store that persists everything. All three live on the user's machine — nothing leaves without their permission.

Diagram 02
One Turn — Message to Response
What happens from the moment the user presses send to the moment June replies. The inner loop can cycle multiple times if June calls several tools in sequence. Mistral (running locally via Ollama) is the decision-maker at the centre — it decides whether to call a tool or reply directly.

Diagram 05
Runtime Flexibility — Swap the LLM Without Changing Logic
The model is resolved once at startup from config.py. Everything above that layer — the agent, tools, memory — is model-agnostic. Swapping from Mistral to Claude or any OpenAI-compatible endpoint requires only changing the .env file.

Diagram 06
The Friend Loop — How June Gets Smarter Over Time
The core value proposition: every conversation enriches the memory, and richer memory makes every future conversation more personal. Unlike a generic chatbot, June's context compounds — she remembers your goals, your habits, your people, and your past.
