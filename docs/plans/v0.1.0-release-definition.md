# v0.1.0 — First Release Definition

## Release Type

**Stable local release.** Desktop (macOS) + Web PWA. No mobile stores, no cloud sync, no account required.

## Release Criteria

All of the following must be true:

### Core Stability
- [ ] API server starts and serves requests without errors
- [ ] Web PWA loads, connects to API, completes first-run setup
- [ ] Desktop app (Tauri) compiles and runs on macOS
- [ ] Ollama supervision: app detects Ollama, prompts to install/start if missing, pulls Gemma 4
- [ ] Chat works end-to-end: user message → agent invoke → token stream → response displayed
- [ ] Memory persists across restarts (SQLite + ChromaDB + KnowledgeGraph)
- [ ] Skills: at least 2 first-party skills work (daily + files), MCP registry is browsable

### Code Quality
- [ ] Python 3.13 upgrade complete, no `Optional[X]` or `Union[X,Y]` in source
- [ ] ActivityLog has no race condition (fix verified)
- [ ] No broad `except Exception` without `logger.exception()`
- [ ] Schema migration system in place (Alembic)
- [ ] API key auth working
- [ ] Data export/import works
- [ ] Test suite passes (pytest brain + api)
- [ ] `ruff check` passes clean
- [ ] `mypy --strict` passes (or explicit suppressions documented)
- [ ] `pnpm check` passes

### Personal Assistant Features
- [ ] Scheduler Service: schedules created, persisted, dispatched
- [ ] Notification Bus: desktop notifications delivered
- [ ] Morning briefing delivered at configured time
- [ ] Evening review delivered at configured time
- [ ] Task recurrence: daily/weekly recurring tasks with carry-forward
- [ ] Chores helper: create, complete, track chores with intervals
- [ ] Shopping assistant: track products, log purchases, set price alerts
- [ ] Telegram integration: bidirectional chat, quick-capture commands, notifications

### Distribution
- [ ] macOS .dmg signed and notarized
- [ ] `brew install june` formula ready (cask)
- [ ] Web PWA at june.ai or equivalent
- [ ] Landing page with install instructions
- [ ] README updated for v0.1.0

## Non-Goals for v0.1.0

- Windows or Linux native builds (macOS only)
- iOS or Android apps
- Cloud sync or hosted backend
- Multi-user profiles
- Voice input/output
- Skill marketplace economics
- Third-party MCP skill signing

## Release Checklist

### 2 weeks before release:
- [ ] Feature freeze: no new features, only bug fixes
- [ ] Dogfood: use June as daily driver for one week, log every issue
- [ ] Performance audit: memory usage, startup time, chat latency

### 1 week before release:
- [ ] Final test suite run
- [ ] Manual QA pass of all major flows
- [ ] Documentation review
- [ ] Create installer builds

### Release day:
- [ ] Tag `v0.1.0` in git
- [ ] Publish GitHub release with .dmg
- [ ] Update landing page
- [ ] Announce on social + Discord
